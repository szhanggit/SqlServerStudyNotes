四，Create Your First Azure Pipeline
Go menu, Dashboard, Data Engineering -Dev, Azure Data Factory, Launch studio
After opening studio, go to select a blue pencil.
Pipelines => New Pipeline => name it as "PL_ingest_ws_sales_to_datalake"
=> Go to Datasets, select new folder, under webstore create new dataset. 
=> Choose "Azure Blob Storage" => Continue => JSON => Name "DS_Online_Sales_Json" => New linked service => Name "LS_abs_webstore"; Description: "Connection to the Web Store blob storage", Storage account name: szwebstoredata01, then Create
=> select file path => ok.
Go back to pipeline:
Open "Move & transform" and pick and drag "Copy data", set General: Name as "Copy Web Store Online Sales Data"; Description as "Copy Online Sales Data from the Web Store and ingest to Data Lake.",
set Source: pick an item in Source dataset.
Sink: "+ New", Azure Data Lake Storage Gen2, Name as "DS_dl_online_sales_json", Create New Linked service, Name as "LS_adls_data_engineering_dl"; Description: "Connection to the Data Engineering Data Lake", Storage account name: szdatalakedev01
Click on the blank space, click "Validate", click "Publish All"

Run Pipline:
Click "Add trigger" => "Trigger now"

Check the running result:
Click bluc clock icon below blue pen => Click "PL_ingest_ws_sales_to_datalake" line to view details.
